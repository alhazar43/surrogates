# Surrogates used by others for two probes (SweepA)

A surrogate here is a measurable quantity that stands in for the exact target of a probe. All six sources were opened in full text (PDF converted to text locally). The cost column is the builder's count from the definition, not a figure from the source. In the assumption and failure columns, "derived" marks a reading of the definition that the source does not state.

## Probe 1. Transfer

Exact target: for a model after practice on task A only, the change of its loss or accuracy on a task B that was not practiced, minus the change that seed noise alone gives for B.

| name | what it computes | source | assumption under which it tracks the target | how it misleads | cost for a small model |
|---|---|---|---|---|---|
| Inter-task affinity (lookahead loss ratio) | Z_{i->j}^t = 1 - L_j(X^t, theta_{s|i}^{t+1}, theta_j^t) / L_j(X^t, theta_s^t, theta_j^t), with theta_{s|i}^{t+1} = theta_s^t - eta grad_s L_i. Averaged over steps | Fifty, Amid, Zhao, Yu, Anil, Finn 2021, Efficiently Identifying Task Groupings for Multi-Task Learning, arXiv 2109.04617v2, section 4.1 Eq. 1; section 4.3 | Hard parameter sharing with task-specific heads. One gradient step on the shared parameters stands for later transfer. The ranking of partners predicts the grouping result only under strong convexity, equal gradient norms and a cosine bound (Proposition 1, section 4.3) | The source gives quadratic-loss counterexamples where the higher-affinity partner gives the higher loss (section 4.3). When no partner stands out, the ranking is flat; the source reports a gap of 0.04 for one Taskonomy objective (section 5, named a limitation) | One extra forward pass per ordered task pair per step, no extra backward pass. About T^2 extra loss evaluations per step for T tasks. Needs a shared trunk with several heads |
| TracInCP (gradient dot product along checkpoints) | TracInCP(z, z') = sum_i eta_i grad l(w_ti, z) . grad l(w_ti, z'). Idealized form: sum over the steps that use z of l(w_t, z') - l(w_{t+1}, z') | Garima, Liu, Kale, Sundararajan 2020, Estimating Training Data Influence by Tracing Gradient Descent, arXiv 2002.08484v3, sections 3.1 (TracInIdeal), 3.2 (first-order form), 3.3 Eq. 1 | Small step size so the first-order term holds. Checkpoints dense enough to stand for every step. Each example visited once between checkpoints (the source says this is needed only for an approximate lemma) | The source gives no failure study of its own for this. Derived: the first-order term fails for a large step or a changing curvature. The value is for the one trained run, so two practice orders give two values. Practice on A and on B in one run is not separated | Two gradients per checkpoint per (practice example, probe example) pair. Linear in the number of saved checkpoints. A last-layer version exists (section 4) |
| Task2Vec distance | Embedding F = diagonal of the Fisher information of a fixed probe network's feature extractor, averaged per filter, after the classifier is re-trained on the task. d_sym = cosine distance of F_a/(F_a+F_b) and F_b/(F_a+F_b). d_asym(t_a -> t_b) = d_sym(t_a, t_b) - alpha d_sym(t_a, t_0), alpha = 0.15 | Achille, Lam, Tewari, Ravichandran, Maji, Fowlkes, Soatto, Perona 2019, Task2Vec: Task Embedding for Meta-Learning, arXiv 1902.03545v1, sections 2.1, 3.1 | The Fisher diagonal of one fixed probe network describes the task. Correlations between filters do not matter. Transfer depends on task similarity and on the complexity of the source task. The alpha value was chosen on their meta-tasks | It scores a pair of tasks, not a trained model, so it does not read what practice did to the weights. The source calls d_asym "improperly" a distance and says it can be negative. Derived: two tasks with equal Fisher diagonals can differ in what they transfer | One probe network, one re-trained classifier and one Fisher pass per task. No training on a pair. The source uses a pretrained ResNet-34 on images; a small model needs its own fixed probe |

## Probe 2. Order

Exact target: for two orders of the same practice items, the distance between the end states of the learner, set against the distance between two runs of the same order with different seeds.

| name | what it computes | source | assumption under which it tracks the target | how it misleads | cost for a small model |
|---|---|---|---|---|---|
| Linear interpolation instability (error barrier) | Train two copies from the same weights W_k with different SGD noise (data order and augmentation). E_sup(W1,W2) = sup over a of E(a W1 + (1-a) W2). Instability is the maximum increase of error above the end points. Stable if about 0 | Frankle, Dziugaite, Roy, Carbin 2020, Linear Mode Connectivity and the Lottery Ticket Hypothesis, arXiv 1912.05671, section 1 and section 2 (Algorithm 1, error barrier height) | Both end states lie in one basin that a straight line shows. Zero barrier is read as the same linearly connected minimum for any sample of noise (section 1) | The noise is random order, not a chosen pair of orders, and order is not separated from augmentation. A zero barrier shows connectivity of the error, not equal functions. A positive barrier can come from a curved low-error path that the line misses (nonlinear connectivity, section 1) | Two runs from a shared checkpoint plus 30 evenly spaced interpolation points (section 2). For a small model, two runs and 30 evaluations |
| Variance of the test metric over data-order seeds | With the weight-initialization seed and the data-order seed varied separately, the standard deviation of validation performance across runs; expected validation performance as a function of the number of runs | Dodge, Ilharco, Schwartz, Farhadi, Hajishirzi, Smith 2020, Fine-Tuning Pretrained Language Models: Weight Initializations, Data Orders, and Early Stopping, arXiv 2002.06305, sections 1, 2, 3.1 | The metric responds to the changed factor and the number of runs is large enough to estimate the spread. The source reports that data order and initialization give variance of comparable size (section 1) | It shows that the spread of the score is nonzero. It does not show that two chosen orders differ in end state. Equal means can hide different weights. The source fine-tunes one model with random shuffling, so a designed order is not tested | N runs per order condition. The source runs hundreds per dataset on four datasets. Linear in N |
| Backward transfer on an accuracy matrix | R_{i,j} = test accuracy on task j after the last sample of task i. BWT = 1/(T-1) sum_{i<T} (R_{T,i} - R_{i,i}). FWT = 1/(T-1) sum_{i>=2} (R_{i-1,i} - b_i), b the accuracy at random initialization. ACC = mean_i R_{T,i} | Lopez-Paz, Ranzato 2017, Gradient Episodic Memory for Continual Learning, arXiv 1706.08840, section 2 (Eq. 2 to 4) | Tasks arrive in a fixed sequence, each seen once. Test accuracy per task stands for the state of that skill | The source defines the matrix for one sequence. Derived: comparing R across two sequences gives an order effect only with the same tasks, the same test sets and a known seed spread. Negative BWT is forgetting and also appears with one sequence | One run per order, and T test evaluations after each of T tasks, so T^2 evaluations per run |
