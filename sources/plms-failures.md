## The 5 lessons that recur most

1. Compute each statistic or rule under no effect, a flat effect, a general effect and the planted effect (with false positive rate and power, at the real size and unit of replication) before the rule is written. Rows 9, 12, 13, 14, 16, 26, 31, 32, 33, 34, 35, 36, 37, 58.
2. Give the control or null the same nuisance as the target (routing, schedule, common factor, format, reliability, order, scale), and read agreement only beside it. Rows 8, 9, 10, 11, 22, 25, 28, 30, 31, 33, 56, 57, 59.
3. Size the target against the floor, the seed spread and the detection threshold before the probe is built, and say which size the design cannot see. Rows 1, 4, 6, 7, 20, 29, 35, 36, 57.
4. A surrogate must track the target and not a larger neighbor (prediction, standing, topic, representation, format, the model's own parameters). Rows 3, 4, 11, 17, 25, 27, 30, 51, 59.
5. Write the next action for each outcome and keep the question the author asked; a probe whose outcomes lead to one action, or a loop on a thin or single-log object, does not run. Rows 2, 19, 37, 40, 41, 42, 43, 44, 47.
